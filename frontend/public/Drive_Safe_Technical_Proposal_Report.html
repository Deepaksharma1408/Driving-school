TECHNICAL SYSTEM ARCHITECTURE & FUNCTIONAL PROCESS REPORT

Executive Summary: This technical brief outlines the fully developed architecture engineered to resolve the core operational pain points of Drive Safe Driving School. It details the step-by-step logic of the Custom 5-Step Booking Engine, the Node.js/PostgreSQL Backend Admin Control Center, and the Gamified Student Progress Portal.
🗓️ SECTION 1: CUSTOM BOOKING LOGIC & DISPATCH WORKFLOW
End-to-End Student Booking Process:

The custom booking engine handles multi-parameter validation to ensure students are paired with the correct vehicle transmission, test location, and available instructor time slot without scheduling overlap.

  • STEP 1
    Transmission & Package Selection:

    Student chooses between Automatic or Manual dual-control vehicle and selects lesson type (Single Lesson, Test Hire, or Combo Package).

  • STEP 2
    Sydney Suburb & Test Centre Filter:

    Matches student location against NSW Transport Test Centres (Botany, Silverwater, Blacktown, Marrickville, Rockdale).

  • STEP 3
    Real-Time Slot Availability Validation:

    Checks backend database for open 90-minute instructor slots, eliminating double-bookings instantly.

  • STEP 4
    Instant Reservation Code & Calendar Sync:

    Generates unique Booking Confirmation ID (e.g. BOOK-847291), triggers automated email receipt, and creates 1-click .ics calendar file for Apple & Google Calendar.

🏆 SECTION 3: GAMIFIED STUDENT PROGRESS & LEARNING MODULES
Student Retention & Progress Gamification:

Replaces static text pages with interactive learning modules that reward students as they progress through their 120 logbook hours.

  • MODULE 1
    Student Milestone Badges (/badges):

    Unlocks gamified badges (Parallel Park Master, Night Driving Hero, P-Plate Ready) with a visual progress bar as logbook hours accumulate.

  • MODULE 2
    360° Vehicle Cockpit Simulator (/cockpit):

    Interactive cabin view featuring hotspot pins detailing dual-pedal safety rules, mirror alignment, and gear shifter posture.

  • MODULE 3
    120-Hour Logbook Calculator (/logbook):

    Interactive Day/Night sliders calculating NSW 3-for-1 bonus instructor hours automatically.

  • MODULE 4
    Service NSW Practice DKT Exam (/quiz):

    10-question practice test module with instant 85% pass/fail scoring badge and NSW Transport rule explanations.
